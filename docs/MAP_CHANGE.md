# マップのレイアウト・テクスチャ変更ガイド

## 1. どこを変えるか（一覧）

| やりたいこと | 場所 | 方法 |
|-------------|------|------|
| **マップのレイアウト**（壁・床の配置） | 各レベルシーン | Godot エディタで TileMap を編集 |
| **タイルの見た目（テクスチャ）** | タイル画像 + TileSet | 画像差し替え or TileSet で設定変更 |
| **敵・コイン・出口などの配置** | 各レベルシーン | エディタでノードの position を変更 |

---

## 2. マップのレイアウトを変える

### 編集するファイル

- **廊下・オフィス**: `Scenes/Levels/MainFloor.tscn`
- **地下室**: `Scenes/Levels/Basement01.tscn`

### 手順（Godot エディタ）

1. **シーンを開く**  
   `MainFloor.tscn` または `Basement01.tscn` をダブルクリックで開く。

2. **TileMap を選ぶ**  
   シーンツリーで `Scene` → `TileMap` を選択。

3. **タイルを塗る／消す**  
   - 下部の **タイルセットパネル** で、使うタイルを選ぶ。  
   - **2D ビュー** でタイルをクリックして配置、右クリックで削除。  
   - グリッドは **32×32**（`Art/TileMap.tres` の `tile_size` に合わせてある）。

4. **保存**  
   `Ctrl+S` でシーンを保存。

※ レイアウトは `tile_map_data` に保存されます。この中身はバイナリに近いため、**レイアウト変更はエディタで行う**のが安全です。

---

## 3. テクスチャ（タイルの絵）を変える

### 3-1. 画像だけ差し替える（推奨）

**使われている画像**

- `Art/Sprites/TileSheet-Sheet.png`  
  → TileSet が **32×32 のタイル**として切り出して使っている。

**手順**

1. **同じレイアウトで絵だけ変える場合**  
   - 既存の `TileSheet-Sheet.png` を別名でバックアップ。  
   - 新しい画像を **同じファイル名**（`TileSheet-Sheet.png`）で `Art/Sprites/` に上書き。  
   - タイルの**並び・数・サイズ**を今のシートと同じにすると、そのまま反映される。

2. **タイルの並びや数を変える場合**  
   - 新しい画像を用意したあと、**TileSet を開いて**タイルの割り当てをやり直す（下記 3-2）。

### 3-2. TileSet の設定を変える（画像パス・タイル割り当て）

**編集するファイル**

- `Art/TileMap.tres`  
  - ここで「どの画像を使うか」「タイルサイズ」「各タイルのコリジョン（壁の当たり）」が決まる。

**主な設定**

- **画像の差し替え**  
  - 3 行目: `path="res://Art/Sprites/TileSheet-Sheet.png"`  
  - 別の画像を使う場合は、ここを新しい画像のパスに変更（例: `res://Art/Sprites/MyNewTiles.png`）。  
  - または Godot で `TileMap.tres` を開き、TileSet エディタの「ソース」でテクスチャを差し替え。

- **タイルサイズ**  
  - 111 行目: `tile_size = Vector2i(32, 32)`  
  - 新しい画像が 32×32 以外なら、こことタイルシートのレイアウトを合わせる。

- **コリジョン（壁判定）**  
  - `TileMap.tres` 内の `physics_layer_0/polygon_0/points` などで、各タイルの当たり判定が定義されている。  
  - 絵だけ変えて「どのタイルが壁か」を変えないなら、触らなくてよい。  
  - 壁の形を変えたい場合は、Godot の **TileSet エディタ**で「物理レイヤー」のポリゴンを編集するのが安全。

---

## 4. 敵・コイン・出口・NPC の配置を変える

これも **レベルシーン**（`MainFloor.tscn` / `Basement01.tscn`）で行います。

- シーンを開き、左のシーンツリーで **Enemy / Pickup4 / AreaExit / NPC など** を選択。  
- 右のインスペクタで **Position**（`position`）の X, Y を変更。  
- または 2D ビューでノードをドラッグして移動。

タイルは 32×32 なので、位置は 32 の倍数（または 16 の倍数）にそろえると、グリッドに揃って配置しやすいです。

---

## 5. まとめ

- **レイアウト変更** → `MainFloor.tscn` / `Basement01.tscn` を開き、**TileMap** をエディタで編集。  
- **テクスチャ変更** → `Art/Sprites/TileSheet-Sheet.png` を差し替える（同じレイアウトならこれだけで OK）。  
- **タイルの割り当て・当たり判定を変える** → `Art/TileMap.tres` を Godot の TileSet エディタで開いて編集。
